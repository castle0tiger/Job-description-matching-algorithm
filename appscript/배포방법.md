# Google Apps Script 배포 방법

## 1단계 - Apps Script 프로젝트 만들기
1. https://script.google.com 접속
2. 좌측 상단 **"새 프로젝트"** 클릭

## 2단계 - 코드 붙여넣기

### Code.gs
- 기본으로 열려있는 `Code.gs` 탭의 내용을 전부 지우고
- `Code.gs` 파일 내용을 복사해서 붙여넣기

### Index.html 추가
- 좌측 파일 목록에서 **"+"** 버튼 클릭 → **"HTML"** 선택
- 파일 이름: `Index` (확장자 없이)
- `Index.html` 파일 내용을 복사해서 붙여넣기

## 3단계 - Gemini API 키 설정
1. 상단 메뉴 **"프로젝트 설정"** (톱니바퀴 아이콘) 클릭
2. **"스크립트 속성"** 탭 클릭
3. **"속성 추가"** 클릭
   - 속성: `GEMINI_API_KEY`
   - 값: 본인의 Gemini API 키
4. **"스크립트 속성 저장"** 클릭

## 4단계 - 웹앱으로 배포
1. 우측 상단 **"배포"** → **"새 배포"** 클릭
2. 유형 선택: **"웹 앱"**
3. 설정:
   - 설명: 아무거나
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자** (또는 본인만)
4. **"배포"** 클릭
5. 권한 요청 승인 (구글 계정 로그인)
6. **웹 앱 URL** 복사 → 브라우저에서 접속!

## 주의사항
- 코드 수정 후에는 "배포" → "배포 관리" → "새 버전"으로 재배포해야 반영됨
- API 키는 "스크립트 속성"에만 저장 (코드에 직접 입력 금지)
